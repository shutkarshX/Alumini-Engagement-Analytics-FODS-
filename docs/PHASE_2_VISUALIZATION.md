# Phase 2 — Data Visualization

## Module 4 Scope

The visualization stage converts the verified Phase 2 EDA findings into graphical analysis.

The visualization script is:

- `R/07_phase2_visualization.R`

It is designed to generate five visualizations:

1. Correlation heatmap of the numeric engagement variables.
2. Event attendance distribution by branch using boxplots.
3. Event attendance comparison by mentorship participation.
4. Average event attendance across graduation batches.
5. Event attendance versus email response with a fitted linear trend.

The generated PNG files are written to:

`outputs/plots/`

## Verification Status

The script has been added to the repository, but the numerical/visual results are only considered verified after the script is executed locally in RStudio.

No visual interpretation is recorded here before execution and inspection of the generated plots.
