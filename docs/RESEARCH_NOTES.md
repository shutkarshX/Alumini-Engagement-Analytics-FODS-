# FODS Research Notes

## Project
Alumni Engagement Analytics

## Research Scope
Research is aligned with the FODS syllabus and the current project phase.

## Phase 1 — Modules 1 & 2

### Module 1: Introduction to Data Science
Relevant concepts:
- data science workflow
- structured and categorical/numeric data
- datasets and data sources
- data classification
- exploratory use of data for institutional analytics

Project application:
- alumni engagement data is represented as a structured tabular dataset
- variables include categorical fields (Branch, Batch, Mentorship) and numeric engagement measures
- synthetic data is used because institutional alumni records are unavailable

### Module 2: Data Pre-Processing
Relevant concepts:
- data preprocessing
- missing values
- noisy/inconsistent data
- duplicate records
- data transformation/standardization

Project application:
- missing values were detected
- duplicate Alumni_ID was detected
- whitespace and categorical inconsistencies were identified
- text values were standardized
- missing numeric values were replaced using medians
- duplicate ID was removed while keeping the first record
- cleaned data was exported for continued analysis

## Phase 2 Research Boundary
Reserved for Phase 2:
- deeper EDA
- outlier identification/removal
- correlation and relationships
- comparative analysis
- additional visualization techniques
- stronger interpretation of engagement patterns

## Evidence Rule
Only research/concepts actually applied or verified during the project should be recorded as completed. Future concepts remain clearly marked as planned.
