# Alumni Engagement Analytics — Dataset

This is a **synthetic project dataset** created for the FODS PBL project because institutional alumni records are not available.

- Records: 250
- Identifier: Alumni_ID
- Engagement measures: event attendance, email response, donations, mentorship, networking events, alumni meetings.

A small number of missing values, inconsistent formatting, and one duplicate ID are intentionally present so Phase 1 can demonstrate data-quality checking and preprocessing.
